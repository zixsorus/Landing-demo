# Surface Brief: Nexura Landing Page (index.html)

## Scope and Visitor Mode
- Target: `index.html` (along with `css/style.css` and `js/main.js`)
- Mode: `Persuade` — the visitor is an engineer or technical decision-maker deciding whether to trust Nexura for production edge stream infrastructure.

## Audience and Intent
- Audience: Backend engineers, platform architects, and SRE leaders.
- Primary Action: Start 14-day free trial, deploy edge cluster, run live API/telemetry simulator.
- Proof: Verified sub-12ms edge latency, real V8 microVM memory snapshots, Anycast topology, multi-language SDK execution.

## Memorable Experience
A calibrated, interactive high-frequency spectrum analyzer & telemetry oscilloscope in the first viewport with live waveform canvas, sweep frequency toggles, and live packet stream telemetry.

## Direction contract

### THESIS
Nexura is framed not as abstract SaaS marketing with floating cards and purple blur orbs, but as a high-precision RF spectrum and telecom network telemetry analyzer. It strictly refuses the category rut of centered generic headlines, stock bento grids, and decorative marketing fluff in favor of rigorous, calibrated instrumentation.

### OWN-WORLD
Chassis in deep instrument black (`#06080b`) and dark gunmetal (`#0e121a`), phosphor cyan and emerald vector traces (`#00f0ff`, `#10b981`), amber alert accents (`#f59e0b`), calibrated 10x10 graticule glass overlays, seven-segment LED telemetry readouts with faint unlit ghost cells, bezel scales, and ruled architectural divider rails.

### STORY
The visitor immediately encounters proof of speed and determinism: sub-12ms Anycast streams measured as live electrical vectors. They inspect real-time 48.4k req/s throughput, test multi-language SDK commands in an authentic dual-pane execution window, inspect the 3-step edge compilation pipeline, review transparent tier pricing, and activate a free cluster.

Calibrated status bar with Anycast sync status; asymmetric hero grid: left 55% presents bold high-spec typographic lockup, technical value proposition, and instant deployment actions; right 45% displays the live RF Spectrum & Signal Vector Console with real-time canvas waveform, graticule grid, frequency markers, and channel controls.
